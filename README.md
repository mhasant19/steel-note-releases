# Steel Note releases

Android builds of **Steel Note**, an offline workout log: routines and multi-week programs, live workouts with a rest timer, paths that level up as you pass their tests, and progress stats. No account, no ads, no tracking.

Website: https://steelnote.pages.dev/

## Install

1. Open the [latest release](https://github.com/mhasant19/steel-note-releases/releases/latest) on your Android phone.
2. Download the `.apk` file under **Assets**.
3. Open it and allow your browser or file manager to install apps when Android asks.

Updates install over the previous version and keep your data. Every release is signed with the same key, so Android only accepts genuine updates.

## Your data

Everything stays on your phone. Google Drive backup is optional and uses a hidden folder only Steel Note can see. Read the [privacy policy](https://steelnote.pages.dev/privacy) and the [terms of use](https://steelnote.pages.dev/terms).
